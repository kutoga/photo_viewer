# Photo Map

A desktop application that displays geotagged photos and videos on an interactive satellite map.

> **Note:** This entire project was generated by AI (Claude by Anthropic).

## Features

- **Satellite map** with ESRI World Imagery tiles (free, no API key)
- **Zoom-adaptive display**: heatmap → cluster bubbles → individual thumbnails
- **Photo & video support**: JPG, HEIC, PNG, TIFF, WebP, MP4, MOV, AVI, MKV, WebM
- **Lightbox viewer** with left/right navigation, video playback, Google Maps link, file path link
- **Gallery view**: browse all photos in the current viewport as a scrollable grid
- **Multi-folder management**: add/remove source directories, rescan on demand
- **Smart caching**: thumbnails (80x80) and previews (1200px wide) stored locally; change detection via file size + mtime
- **Labels overlay**: street names, place names, and borders
- **Media filter**: show photos only, videos only, or all
- **Spiderfier**: click a cluster to expand photos in a circular layout
- **Built-in help** accessible via the `?` button

## Requirements

- [Node.js](https://nodejs.org/) LTS (v18+)

## Setup

```bash
npm install
npm start
```

The `postinstall` script automatically rebuilds `sharp` for Electron and copies vendor libraries (Leaflet, supercluster, leaflet-heat) into `renderer/vendor/`.

On Windows you can also double-click `start.bat`.

## How It Works

1. Click **+ Add Folder** to select a directory containing photos/videos
2. The app scans for GPS-tagged media in the background, extracting EXIF data and generating cached thumbnails/previews
3. Photos appear on the satellite map at their GPS coordinates
4. Zoom out for a heatmap overview, zoom in to see individual thumbnails
5. Click any thumbnail to open the lightbox with full navigation

## Tech Stack

- **Electron** — desktop shell (main + renderer process)
- **Leaflet.js** — interactive map with ESRI satellite tiles
- **Leaflet.heat** — heatmap layer for zoomed-out view
- **supercluster** — fast viewport-aware point clustering
- **exifr** — EXIF/GPS extraction from photos
- **sharp** — image resizing for thumbnails and previews

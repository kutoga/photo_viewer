Getting Started

Click + Add Folder to select a folder containing photos or videos. The app scans for GPS-tagged media and displays them on the satellite map.

Map Navigation

  • Zoom out — heatmap overview of photo density
  • Zoom mid — cluster bubbles showing photo count (click to expand)
  • Zoom in — individual photo thumbnails on the map

Viewing Photos

  • Click any thumbnail to open it in the lightbox
  • Use ← → arrow keys or the on-screen arrows to navigate
  • Press Esc or click the backdrop to close
  • Coordinates link to Google Maps · file path reveals in explorer

Controls

  • Show labels — overlay street names and place labels
  • Media filter — show photos only, videos only, or all
  • Gallery — browse all photos in the current view as a grid
  • Refresh ↻ — rescan all folders for new or changed files

Keyboard Shortcuts

  • Esc — close lightbox / gallery / help
  • ← / → — previous / next photo in lightbox
